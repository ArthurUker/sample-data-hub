# 数据模型与字段草案

## 1. 样本

核心作用：作为系统主实体，承载唯一样本编号。

建议字段：

1. 样本编号
2. 样本类型
3. 样本来源
4. 采样日期
5. 送检日期
6. 当前状态
7. 当前最终版版本号
8. 创建时间
9. 更新时间

## 2. 检测记录

核心作用：表示某个站点提交的一次检测数据。

建议字段：

1. 检测记录 ID
2. 样本编号
3. 站点
4. 数据来源类型
5. 录入人
6. 录入时间
7. 备注
8. 所属版本号

## 3. 检测项目明细

核心作用：逐项目记录 Ct 值和结论，避免把多个项目塞在同一行难以比较。

建议字段：

1. 明细 ID
2. 检测记录 ID
3. 检测项目名称
4. Ct 值数值字段
5. 原始文本字段
6. 结论
7. 是否缺失
8. 单位或说明

## 4. 版本

核心作用：保留所有修改历史，支持审核与回溯。

建议字段：

1. 版本 ID
2. 样本编号
3. 版本序号
4. 来源操作类型
5. 修改人
6. 修改时间
7. 修改说明
8. 是否当前最新版本
9. 是否被审核选为最终版

## 5. 比对结果

核心作用：存储自动计算的差异结果，不允许直接手工修改。

建议字段：

1. 样本编号
2. 检测项目
3. 参与比对的版本集合
4. 最小 Ct
5. 最大 Ct
6. 差值
7. 当前阈值
8. 比对状态
9. 是否需要审核

## 6. 审核结果

核心作用：记录最终版决策。

建议字段：

1. 审核 ID
2. 样本编号
3. 审核人
4. 审核时间
5. 选定版本
6. 审核结论
7. 审核备注
8. 是否生效

## 7. 核心规则

1. 每次新增或编辑必须生成新版本。
2. 导入数据不覆盖历史数据，只追加版本。
3. 对外展示与导出默认采用最终版。
4. 原始文本值需要保留，标准化值单独存储。
