# 开发路线与阶段目标

## 阶段 1：文档确认

1. 确认业务规则
2. 确认字段清单
3. 确认页面范围
4. 确认比对规则
5. 确认审核机制

## 阶段 2：数据骨架

1. 建立数据模型
2. 明确版本机制
3. 明确审核定版逻辑
4. 明确导入与比对模块边界

## 阶段 3：最小可用界面

1. 样本总览
2. 样本详情
3. 在线录入
4. 差异列表

## 阶段 4：Excel 流程

1. 导入模板
2. 导入校验
3. 导出最终版

## 阶段 5：上线准备

1. 角色权限校验
2. 操作日志
3. 初始化数据导入
4. 部署与测试

## 第一版验收标准

1. 能创建和检索样本。
2. 能录入多个站点的检测记录。
3. 能保留所有历史版本。
4. 能对同一样本的检测项目做阈值比对。
5. 能列出差异样本。
6. 审核人能选定最终版。
7. 导出时只导出最终版。
8. 能从 Excel 导入数据并生成版本。
9. 能追溯修改历史。
