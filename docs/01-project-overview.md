# 项目总说明

## 1. 项目背景

当前样本检测数据主要通过 Excel 表格在多方之间共享和编辑，存在以下问题：

1. 同一个样本编号的数据分散在不同表格与不同人员手中。
2. 多方同时修改时缺少版本追踪，容易覆盖历史信息。
3. 同一样本编号下的多次检测和多方检测缺少自动比对能力。
4. 最终对外采用哪个版本缺少明确审核机制。

## 2. 项目目标

建设一个浏览器网页系统，用于统一管理样本检测数据，并支持多人协同录入、版本保留、自动比对与审核定版。

第一版目标：

1. 样本编号全局唯一。
2. 检测记录按站点归属。
3. 同一样本按检测项目进行 Ct 值比对。
4. Ct 差异阈值支持参数化配置。
5. 所有历史修改保留版本。
6. 最终版必须由审核人确认。

## 3. 第一版范围

纳入范围：

1. 样本台账管理
2. 检测数据录入与编辑
3. Excel 导入
4. 自动差异比对
5. 差异审核与最终版确认
6. 操作日志与版本追溯
7. Excel 导出

暂不纳入范围：

1. 小程序端
2. 消息通知系统
3. 统计分析大屏
4. AI 自动判定
5. 复杂审批链

## 4. 已确认规则

1. 样本编号唯一。
2. 数据主归属按站点。
3. 比对粒度为样本编号 + 检测项目。
4. 差异判定使用可调阈值。
5. 历史数据全部保留版本。
6. 所有人都可以修改历史数据。
7. 审核人负责确认最终版。
8. 最终版不会因普通修改自动替换。

## 5. 角色

1. 管理员：管理用户、站点、参数、模板和导出。
2. 录入员：录入和编辑检测数据，生成新版本。
3. 审核人：处理差异、选择最终版、填写审核意见。
4. 只读查看者：查看台账和最终结果。
