# 页面结构与流程草案

## 1. 页面清单

### 登录页

用于用户登录并进入对应角色工作区。

### 样本总览页

用于按样本编号、站点、状态、差异状态、审核状态进行筛选和检索。

### 样本详情页

核心页面，集中展示：

1. 样本基本信息
2. 全部检测记录
3. 各版本时间线
4. 按检测项目的比对结果
5. 审核结论与最终版

### 录入与编辑页

用于新增检测记录，或基于历史版本复制后修订。

### Excel 导入页

用于模板上传、字段映射、预览校验和导入结果反馈。

### 差异审核页

用于审核人集中处理存在差异或需要复核的样本。

## 2. 核心流程

### 录入流程

1. 创建或检索样本。
2. 录入站点检测记录。
3. 系统生成新版本。
4. 系统自动重算比对结果。
5. 若存在差异，则进入待审核。

### Excel 导入流程

1. 上传 Excel 文件。
2. 识别模板与字段映射。
3. 校验样本编号、站点、检测项目和 Ct 字段。
4. 生成预览结果。
5. 导入后创建新记录和新版本。

### 审核流程

1. 审核人查看差异样本。
2. 对同一样本的各版本和比对结果进行判断。
3. 选择某一版本作为最终版。
4. 填写审核意见。
5. 系统将最终版作为默认展示和导出数据。

## 3. 比对逻辑

按样本编号聚合，再按检测项目逐项比较 Ct 值。

差值计算：

- 差值 = 最大 Ct - 最小 Ct

规则：

1. 当差值小于等于阈值时，视为阈值内一致。
2. 当差值大于阈值时，视为差异并标红。
3. 特殊文本值保留原始内容，不直接参与数值计算。
